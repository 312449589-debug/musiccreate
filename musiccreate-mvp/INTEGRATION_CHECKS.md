# 接口对齐验证记录

依据：用户提供 API_CONTRACT.md 草案 v1。

## 已验证

自动化测试使用隔离的模拟响应，覆盖：

- 提交字段、guitar 映射、用途、英文 style_tags，未传 user_id。
- Bearer 用户 token、UUID Idempotency-Key。
- 提交断网后同请求内容、同幂等 key 重试。
- 保存失败不显示成功，保存成功使用服务端返回作品。
- 列表分页、重复 ID 去重、不透明 ID/cursor 编码。
- 练习主动提交，分钟转秒、UTC 时间、自我确认字段。
- 练习保存失败保留表单，响应成功后显示保存结果。
- 401 身份通知，429 Retry-After 和等待期间不发送新请求。
- 已有任务仅 GET 恢复查询、failed 状态、403 暂停保留任务。
- 非 HTTP(S) 音频 URL 拒绝。
- JavaScript 语法检查。

浏览器临时模拟接口验证：

- 两步初始设置，首版仅吉他。
- 创建任务，queued → processing → succeeded，返回 Demo。
- 服务端音频 URL 播放，进度实际推进。
- 保存 Demo、作品列表、详情读取、设为练习目标。
- 主动勾选弹会目标段落，保存 15 分钟练习，显示响应结果。
- 桌面布局与手机窄屏布局；未发现横向溢出。
- 没有后端的普通静态预览明确显示接口不可用，不回退本地生成。

截图 api-desktop-test.png / api-mobile-test.png 位于交付目录的上一级，显示的是模拟接口数据，不是线上后端结果。临时 mock adapter 与音频不在正式包中。
